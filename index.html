How to read this map

Boundaries show provincial-level administrative units. Colour shows the number of records whose metadata names that province. “Cultural region” is the project’s separate classification; songs retain that label in each province’s profile. Ambiguous and missing province labels are left unassigned.

Boundary geometry: Tianditu national-standard vector data, distributed as GeoJSON by GeoJSON.cn (CGCS2000 / EPSG:4490). Geometry is simplified for web display. Record metadata: metadata/recordings.csv. No audio is hosted here.
