## Paper & Description Insights
The Dunya platform hosts collections of music from various traditions including Jingju (Beijing Opera). Provides API access for developers to query and retrieve audio recordings, metadata, and analysis results. The Jingju collection includes full recordings and associated musicological annotations.

Access requires API registration through the Dunya developers portal.

## Content & Taxonomy Analysis
- Time period: Traditional Beijing Opera repertoire
- Region: Beijing / northern China
- Genre/form: Jingju (full recordings, not just a cappella excerpts)
- Instrumentation: Full Beijing Opera ensemble (vocals + accompaniment)
- Musical system: Traditional jingju
- Language: Mandarin Chinese (classical theatrical)
- Modalities: Audio recordings, metadata, analysis features
- Labels: Musicological metadata via Dunya API
- Note: API-gated access; may contain more comprehensive recordings than the Zenodo excerpt datasets
