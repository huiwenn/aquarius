## Paper & Description Insights
This is the resources page of the same researcher behind MGD. References 31,000+ songs in the MGD collection and 1,214 selected songs in MGDplus. MGDplus features five annotations per song from seven geographic regions with partial audio-score alignment.

Since this substantially overlaps with MGD, this doc serves as a cross-reference. The primary dataset doc is `mgd.md`. The 1,214-song subset (MGDplus) may warrant separate treatment if it has distinct annotations or audio data.
