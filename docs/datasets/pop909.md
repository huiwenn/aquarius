## Paper & Description Insights
POP909 is a dataset of 909 Chinese pop songs designed for music arrangement generation research. Each song has MIDI files with separated arrangement tracks (melody, sub-melody, accompaniment), beat timing information (from both audio and MIDI), chord annotations with timestamps, and key change information. Pre-processed versions in Magenta event token format are also available.

The dataset is notable for its scale (909 songs) and the quality of arrangement-level annotations, making it valuable for studying melody-accompaniment relationships in Chinese pop music. Multiple professional piano arrangement versions per song allow study of arrangement variation. The repository also includes processing scripts for converting MIDI to Magenta event token format.

### MIDI Files

#### Main MIDI files (909 total)
- **Tracks per file**: Always 3 (MELODY, BRIDGE, PIANO)
  - MELODY: Main vocal melody (avg 332 notes, range 200-465)
  - BRIDGE: Sub-melody / counter-melody (avg 246 notes, range 43-829)
  - PIANO: Accompaniment (avg 1,045 notes, range 516-1,764)
- **Duration**: 156-326 seconds (mean 251s, median 254s)
- **Tempo**: 55-123 BPM (mean 76 BPM) — note: these are MIDI-embedded tempos
- **Time signatures in MIDI header**: 1/4 (most common), 4/4, 2/4, 3/4
- **MIDI key signatures**: Sparsely set (only 9 of 50 sampled had key_signature events, all C Major — likely default)

#### Version MIDI files (1,989 total)
- Represent professional arrangement versions of each song
- modify_times in index.xlsx corresponds to version count:
  - 1 version: 343 songs
  - 2 versions: 287 songs
  - 3 versions: 142 songs
  - 4 versions: 84 songs
  - 5 versions: 26 songs
  - 6+ versions: 27 songs
- Track names: primarily MELODY/CAU/PIANO (or lowercase variants); some versions use descriptive names (e.g., "Steinway Grand Piano", "Grandeur 1")

### Annotation Files

#### Beat annotations (beat_audio.txt, beat_midi.txt)
- **beat_audio.txt**: 2 columns — `time(sec) beat_position`
  - beat_position values: 1.0, 2.0, 3.0, 4.0 (downbeat = 1.0)
- **beat_midi.txt**: 3 columns — `time(sec) is_beat is_downbeat`
  - is_beat: 0.0 or 1.0
  - is_downbeat: 0.0 or 1.0

#### Chord annotations (chord_audio.txt, chord_midi.txt)
- **Format**: 3 columns — `start_time end_time chord_label`
- **Unique chord labels**: 930
- **Chord vocabulary**: Uses `root:quality` notation (e.g., `C:maj`, `A:min7`)
  - "N" = no chord / silence
- **Top chord qualities** (by frequency):
  - maj: 91,887 occurrences
  - min: 56,003
  - min7: 17,909
  - N (no chord): 6,202
  - maj/3 (first inversion): 5,954
  - sus2: 5,786
  - maj7: 5,536
  - 7 (dominant): 4,866
  - sus4: 3,290
  - maj/5 (second inversion): 3,156
  - And 100+ additional qualities including: maj(9), maj6, dim, aug, hdim7, min9, maj9, sus4(b7), min/b3, etc.
- Chord notation includes inversions via slash (e.g., `maj/3`, `min/b3`, `maj/5`)

#### Key annotations (key_audio.txt)
- **Format**: 3 columns — `start_time end_time key_label`
- **Key vocabulary**: 24 keys (all 12 major + 12 minor)
- **Key distribution**: C:maj (69), G:maj (63), F:maj (58), E:min (56), Db:maj (54) most common
- **Key changes per song**:
  - 1 key (no changes): 757 songs (83%)
  - 2 keys: 124 songs (14%)
  - 3+ keys: 28 songs (3%)

### Artist Statistics

### Custom Formats & Conventions
- Chord annotation uses a variant of the Harte notation (MIREX chord notation): `root:quality[/bass]`
- beat_midi.txt uses a 3-column binary indicator format (beat, downbeat) instead of beat position numbers
- beat_audio.txt uses beat position numbers (1-4, cycling)
- The `modify_times` field indicates how many professional arrangement versions were created for each song, matching the number of files in the `versions/` subdirectory
- MIDI track names encode arrangement roles: MELODY (vocal), BRIDGE (sub-melody), PIANO (accompaniment) in main files; CAU (accompaniment) in version files

## Content & Taxonomy Analysis
- **Time period**: Contemporary Chinese pop (spanning roughly 1980s-2010s based on artist roster)
- **Region**: Pan-Chinese pop — mainland China, Taiwan, Hong Kong artists
- **Genre/form**: C-pop / Mandopop / Cantopop
- **Instrumentation**: Not explicitly labeled per instrument; arrangement tracks separated by musical role:
  - MELODY: vocal melody line
  - BRIDGE / sub-melody: counter-melody or secondary melodic line
  - PIANO / CAU: accompaniment (piano reduction)
- **Musical system**: Western diatonic/chromatic (chord annotations use Western chord notation with Harte-style labels)
- **Language**: Mandarin Chinese pop songs (some Cantonese); lyrics not included, MIDI only
- **Modalities**: MIDI (primary), beat annotations (text), chord annotations (text), key annotations (text)
- **Labels present**:
  - Beat positions (from audio + MIDI analysis)
  - Chord names with timestamps (from audio + MIDI analysis) — 930 unique labels, Harte notation
  - Key (major/minor) with timestamps — 24 keys
  - Arrangement role (MELODY / BRIDGE / PIANO)
  - Song metadata: title, artist, modify_times, beats_per_measure, quavers_per_beat
  - Time signature (2/4 or 3/4 via num_beats_per_measure)
  - Tempo (embedded in MIDI, range 55-123 BPM)
  - Multiple professional arrangement versions per song (1-9 versions)
- **Labels NOT present**: genre sub-categories, mood, singing technique, lyrics, language tag, year of release, composer (distinct from artist), album

## Gap Assessment

### Strengths for Aquarius
- Large-scale (909 songs) Chinese pop music dataset with professional annotations
- Rich chord vocabulary (930 unique labels) with both audio-derived and MIDI-derived annotations
- Key and beat annotations with timestamps enable fine-grained musical analysis
- Multiple arrangement versions enable studying arrangement practices in C-pop
- Artist metadata enables artist-level analysis (462 unique artists)
- MIT license — no access restrictions
- Song titles and artist names in Chinese (UTF-8 encoded, no encoding issues)

### Gaps / Limitations
- **No audio**: MIDI-only dataset; original audio not included (was used for annotation but not distributed)
- **No lyrics**: Despite being vocal pop songs, no lyric text is provided
- **No year/era metadata**: Cannot directly study temporal trends without external linking
- **No genre sub-tags**: All songs labeled generically as "Chinese pop" — no finer genre distinctions (ballad, rock-pop, dance-pop, etc.)
- **No mood/emotion labels**: No affective annotations
- **No explicit language tag**: Mostly Mandarin but some Cantonese artists present; no per-song language label
- **No composer field**: Only performer/artist provided, not songwriter/composer
- **Limited time signature variety**: 97% of songs are in duple meter (2 beats per measure)
- **MIDI key signatures unreliable**: Most MIDI headers default to C Major; the key_audio.txt annotations are the authoritative key source
- **Song selection criteria unknown**: Paper does not describe how the 909 songs were chosen from the broader C-pop repertoire
