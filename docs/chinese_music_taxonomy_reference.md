# Chinese Music Taxonomy Reference

Reference framework for categorizing Chinese music. This is a **guiding lens**, not the database schema — the actual schema is derived as the superset of features found across all collected datasets.

## Temporal
- Dynasty/historical period: Tang, Song, Yuan, Ming, Qing, Republican era, Contemporary
- Approximate date range (for pieces that span or are ambiguous)

## Regional/Cultural
- Geographic origin: province-level + broader region (North/South/ethnic minority regions like Xinjiang, Tibet, Inner Mongolia)
- Ethnic group (Han vs. 55 recognized minorities — many have distinct musical traditions)
- Urban vs. rural tradition

## Musical System
- Tonal system: pentatonic modes (gong/shang/jue/zhi/yu 宫商角徵羽), heptatonic variants (yayue 雅乐, qingyue 清乐, yanyue 燕乐 scales), vs. Western diatonic/chromatic
- Tuning system (e.g., sanfen sunyi 三分损益 vs. equal temperament)

## Genre/Form
- Traditional: instrumental solo, ensemble, opera (jingju 京剧, kunqu 昆曲, yueju 越剧, etc.), folk song (shan'ge 山歌, haozi 号子, xiaodiao 小调), narrative singing (quyi 曲艺), ritual/ceremonial
- Modern: C-pop, Mandopop, Cantopop, Chinese rock, guofeng 国风 (national style pop)
- Cross-genre / fusion

## Instrumentation
- Traditional instrument families via bayin (八音) classification: silk (si 丝), bamboo (zhu 竹), metal (jin 金), stone (shi 石), earth (tu 土), leather (ge 革), gourd (pao 匏), wood (mu 木)
- Western instruments
- Electronic/synthesized

## Modality (data representation)
- Audio (WAV/MP3/FLAC)
- MIDI
- MusicXML / staff notation score
- Jianpu (numbered notation 简谱)
- Lyrics
- Metadata-only
